# FocusPilot 规范（SPEC v0.1）

## v0.2当前智能录入契约（2026-10-24）

- 文本1–8000字，一轮1–5项草稿。JSON包含title、due_at、importance、estimated_minutes、source_text、due_note和field_sources；封闭字段/范围校验，引用必须是原输入连续片段。
- 真实Pi仅两个只读MCP工具。应用还核对模型实际查重标题覆盖最终清单，并在显示/保存前做确定性查重；失败或截断不能视为无重复。候选是同名未完成任务，不是语义去重。
- 明确日期加钟点由本地规则换算，保留已过期的明确日期，不自动延后；模糊时间留空。重要程度/耗时可建议但标注。未识别的日期格式留给用户，不把模型自称explicit当作充分证据。
- 流程：确认数量/清单 → 丢弃新增或仍然新增 → 检查各项字段 → 明确保存全部。缺失DDL必须补充或勾选不设置。确认前仅内存草稿；保存使用单SQLite事务，失败全部回滚。
- 取消使运行/草稿失效并保留原文，后台回收本轮进程/通道；旧结果不可更新界面。不删除已保存任务，不回滚外部API费用。
- AppContainer先挂起、入Job、核验SID/零能力再执行；每轮验证不能直接打开数据库。固定模型加密通道仅连接DeepSeek；MCP、模型、RPC各自有界。无普通权限回退或自动收费重试。
- 已有Qt提醒逻辑独立运行。下文“尚未实现/未启动”等为早期阶段历史，当前实际证据以VALIDATION与T08快照为准。

## 总体架构原则

Local-first、fail-safe。提醒与存储完全独立于模型。Agent 对外通过受限 Tool API 访问任务；对原始 DDL 的改变必须由用户确认。

## 数据模型

- `id`: UUID
- `title`: 非空字符文本
- `due_at`: 可空，本地 `YYYY-MM-DDTHH:MM:SS`（V0.1 暂存本地时间）
- `importance`: 1（低）/2（中）/3（高）
- `estimated_minutes`: 1–1440
- `status`: `pending`/`done`
- `created_at`: 本地时间
- `snoozed_until`: 用户主动推迟结束时间，可空
- `reminder_stage`: `none`/`soon`/`overdue`/`snoozed`

## V0.1 规则（已实现）

R1. 任务标题为空不可保存。
R2. 无 DDL 允许保存，不触发截止提醒。
R3. 已完成任务不参与排序和提醒。
R4. 当前时间 >= DDL，属于紧急且触发一次逾期提醒。
R5. 当前时间距 DDL <= 2 小时，属于紧急；<= 24 小时或高重要程度属于优先。
R6. 剩余 <= 30 分钟首次触发截止提醒；同一提醒阶段仅通知一次。
R7. 用户选择推迟 10 分钟后，推迟结束之前不通知；到期后再次检测阶段。
R8. SQLite 写入后重启应用，任务仍存在。
R9. 用户关闭主窗口时，只要系统托盘存在，程序继续运行。

## V0.1 接受标准

A1. 能创建有/无 DDL 任务，排序和显示。
A2. 关闭重启后任务仍可读取。
A3. 测试覆盖截止前提醒、逾期提醒、推迟后重试、不提醒已完成任务。
A4. 真实 Windows 验收：系统托盘点击可恢复界面；背景提醒仍在运行。
A5. 真实 Windows 验收：禁用系统通知时面板仍显示任务；提醒不保证穿透系统专注模式。

## 后续 Pi Agent 的接口契约（尚未实现）

输入：当前任务和可选用户上下文；外部文档必须来自白名单。

允许默认调用：`list_tasks`、`propose_plan`；`create_task` 需用户确认解析内容；`complete_task`、`change_deadline` 等影响正式状态的写操作必须受到应用侧许可检查。

返回：结构化每日计划，包含任务 ID、建议排序、原因、风险提示、缺失字段；不要凭空补全截止时间。

Pi RPC 客户端必须区分 `prompt` 接受确认与 `agent_settled` 执行完成；按 JSONL 解析事件且不在桌面主线程中阻塞等待。

## T04 默认方案（2026-10-22）

- 使用 Windows RegisterHotKey 注册 Ctrl+Alt+N，并设置 MOD_NOREPEAT；通过 Qt 原生事件过滤器处理 WM_HOTKEY，排队打开现有录入表单。已打开表单时只恢复该表单，不重复创建。
- 注册冲突不抢占其他应用的热键，不影响普通按钮录入；底部显示原因。退出和会话结束时释放资源；正常隐藏保留热键。Ctrl+Q 是主窗口内的退出快捷键。
- 登录自启默认关闭，仅在用户勾选时写入 HKCU 的 Run/FocusPilot 值；使用绝对 pythonw 路径和 `-m focuspilot --background`，正确引用含空格路径，并检查260字符限制。取消只删除本应用的值。读写失败可见且不将界面错误地保留为启用。
- `--background` 优先驻留托盘，托盘不可用时显示主窗口。属于用户登录后启动，不承诺登录前运行或固定启动时刻。
- 同一数据库路径通过 QLockFile 限制单实例，QLocalServer 仅允许当前用户访问。重复启动通过本地 IPC 请求恢复已有窗口，并等待确认后退出；崩溃后可恢复锁，不产生多实例重复提醒。
- Qt 会话结束请求设置 RestartNever 并清理计时器、表单、托盘、热键；不阻止系统注销。所有写入操作即时提交，异常进程终止后的数据和锁恢复由跨进程测试覆盖。
- 不自动启用自启，不在开发验收中注销或重启用户电脑。真实登录/注销与OS通知策略的最终验收独立记录。

实现依据：[RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)、[Run registry keys](https://learn.microsoft.com/windows/win32/setupapi/run-and-runonce-registry-keys)、[Qt native event filter](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QAbstractNativeEventFilter.html)。

## T05 提醒策略（2026-10-22）

- 用户明确选择“逾期任务仍强提醒”。默认普通提醒为标准模式、工作时段限制关闭、免打扰关闭、逾期强提醒例外开启、通知最小间隔1分钟。
- 三种普通提醒方式：仅面板（无横幅/自动恢复/声音）、标准（横幅，逾期恢复面板）、强提醒（横幅、恢复面板、一次系统提示音）。逾期例外开启时，逾期任务始终使用强提醒，即使普通模式为仅面板、处于免打扰或工作时段外；设置中明确说明且可关闭该例外。
- 工作时段每天重复，开始包含、结束不包含，支持22:00–06:00等跨午夜区间；起止相同不能保存，全日提醒用关闭限制表示。本阶段仍使用本地墙上时间，不扩展T06时区范围。
- 免打扰为一次性本地结束时间，到达精确结束时刻后失效；此后仍需满足工作时段。被抑制的阶段不标记已处理；恢复后只根据当前状态汇总，例如已经逾期时只提醒overdue，不补发soon。已完成任务不补发。
- 每个阶段一次；任务“稍后10分钟”仍优先于逾期例外。强提醒不会循环鸣响、持续抢焦点或反复弹窗。同批外部提醒只汇总一个横幅、最多一次面板恢复和一次提示音。
- 通知最小间隔为1–60分钟，适用于包括逾期例外在内的所有主动提醒；冷却期间保留待处理阶段，界面持续显示任务。间隔时间保存在SQLite，重启不会清零。系统时间回退时不会无限延迟提醒。
- 仅面板模式的无打扰更新可记录阶段，但不消耗外部通知间隔；切换方式不会重播已处理阶段。不能把“任务仍可见”和“OS横幅实际送达”混为一谈。
- 设置与最近通知时间保存在新增app_settings表，不修改tasks中的DDL、重要程度、状态或排序依据。批量提醒阶段和通知时间在同一事务提交；事务失败不发出副作用，并在下一次检查重试。
- 保存失败保留表单输入和原有效设置；取消不写入。配置损坏时显示错误并暂用仅面板、无逾期例外的静默回退，不覆盖损坏原文；用户明确保存后恢复正常。
- 应用内强提醒不能保证穿透Windows专注模式、系统通知策略或静音；响铃依赖系统音量。操作系统设置保持由用户管理。

## T07 离线实现边界（2026-10-23）

- 用户已授权开始离线代码实现。现有生产GUI不接入模型；新增独立`focuspilot.offline_demo`，只使用临时虚构数据。T08草稿和确认表单仍未实现。
- `rpc.py`实现LF字节分帧、显式大小/深度限制、纯运行状态机与只读业务查询。运行成功要求接受确认、收敛事件、最终正常文本和无未恢复错误，不把提示词响应当作完成。
- `pi_runtime.py`通过QThread管理子进程、连续读stdout和独立诊断流，通过信号更新GUI。每个进程仅一轮分析，不复用旧事件流；重复提交被拒绝。命令来自可信应用配置，`shell=False`，不接受模型提供的命令行。
- 默认总时限60秒、停止宽限1秒、工具事件次数上限8，可通过RunPolicy配置；使用单调时钟。超限停止属于事件观察层防护，真实扩展还须在工具执行前检查预算。
- 取消立即使运行失效，停止和EOF在后台执行，宽限后仅终止本轮自己启动的子进程。失败/超时保留输入，不静默重新提交模型请求。
- 工具只接受固定`list_tasks(limit)`和`find_duplicate_tasks(titles)`参数，使用只读URI及query_only连接、固定查询与参数绑定，仅返回未完成任务必要字段；限制结果数量并返回truncated。截断不能解释为完整查重。
- 假Pi直接复用只读模块模拟工具执行；官方RPC工具事件不是宿主执行授权。真实Pi扩展桥接、工具权限强制执行、进程级沙箱和真实模型调用尚未实现，不把环境变量裁剪当作安全隔离。
