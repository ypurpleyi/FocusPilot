# FocusPilot v0.2 使用说明

本机入口：双击项目文件夹内`FocusPilot.cmd`或桌面FocusPilot快捷方式。关闭窗口会进入托盘，真正退出使用托盘菜单或主窗口Ctrl+Q。

## 智能录入

1. 点击「粘贴通知 · 分析待办」，粘贴或输入任务通知，一次最多5项、8000字。
2. 点击分析。首次使用准备约194MiB的专属Pi副本；随后调用已配置的DeepSeek Flash，可能产生API费用。
3. 确认“识别到X项任务”的数量和清单。不正确可返回修改原文。
4. 若有同名未完成任务，选择丢弃本次新增或仍然新增；不会删除或修改旧任务。
5. 逐项检查自动填充字段。重要程度/耗时的建议值有标注；不明确的截止时间由你补充，或明确勾选不设置。
6. 点击「保存全部待办」后，应用才在一个事务中保存。中途取消不保存部分任务。

示例：`明天17点提交周报，高优先级，预计30分钟。整理项目资料，无截止日期，预计45分钟。`

明确日期加钟点由本地规则换算；“明天下午”“尽快”等不猜具体时间。当前采用本机本地时间，尚不支持跨时区旅行/日历同步的完整语义。

## 取消和失败

- 点击「取消本次分析」立即回到保留原文的界面。后台完成清理后才能启动新分析，迟到结果不会覆盖界面。
- 取消不能撤销已经发送的模型请求或费用，也不会删除已保存任务。
- 查重、模型、配置、隔离或连接失败时停止并保留原文；不会把失败解释为没有重复，也不自动收费重试。
- 保存失败时草稿保留，可重试保存，无需再次请求模型。
- 本地手动录入、排序、完成、推迟与提醒不依赖Agent。

## 数据与运行环境

数据库：`%APPDATA%\FocusPilot\tasks.sqlite3`。不把数据库、密钥或运行缓存上传Git。模型只会接收你点击分析时提交的文本和必要的只读查询结果。

本机已验证Python3.13.5/PySide6 6.9.3、MCP2.3.0、pywin32312、Node24.15.0和Pi1.4.0。密钥从本机Pi的DeepSeek配置中选取，原配置不修改；不支持此入口自动执行取密命令或OAuth刷新。

Pi运行于零网络能力的AppContainer，只能经受限通道查询任务和访问固定DeepSeek服务。宿主MCP服务属于可信应用代码；只读连接不是对宿主进程全部权限的OS隔离。

登录自启默认由用户勾选启用；系统通知的实际显示/声音受Windows设置影响。当前未实现任务编辑/删除、每日规划、第三方文档/日历接入或完整跨时区处理。
